# 定盘 · 升学评测（广东 3+1+2）

一个可点击的移动端交互原型：输入高考一模、二模成绩，换算成全省位次，推测可被哪些院校专业组录取。

在线预览：https://zhumin2.github.io/dingpan/

## 这是什么

- **单文件 HTML**：`index.html` 自包含，无构建、无外部数据文件，双击即可打开。
- **完整闭环**：录入 → 换算 → 冲/稳/保三档推荐 → 院校专业组详情 → 加入志愿表 → 梯度体检。
- **可复算的口径**：点「匹配口径」能看到等效分加权、位次区间与录取概率公式，页面上的数字都是算出来的。

## 算法说明

| 环节 | 做法 |
| --- | --- |
| 等效分 | `0.4×(一模+Δ₁) + 0.6×(二模+Δ₂)`，Δ = 2025 特控线 − 模考特控线，结果限制在 0–750 |
| 波动区间 | 等效分 ± `(|一模−二模| / 2 + 4)` |
| 位次 | 内置一分一段表按锚点分段对数插值，分数与位次互逆 |
| 录取概率 | `1/(1+e^((我的位次−组位次)/(0.16×组位次)))`，限制在 3%–97% |
| 分档 | 概率 <50% 为冲，50–82% 为稳，≥82% 为保；每档按位次接近程度取最近 10 个 |

## 重要提醒

页面中所有院校、专业组、投档分数与位次均为**演示数据**（物理 34 组 / 历史 20 组），不构成任何填报依据。正式上线需接入广东省教育考试院历年投档统计表与当年招生计划。
